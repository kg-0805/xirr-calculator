How to Use

  1. Prepare an Excel file (.xlsx or .xls) with Date, Type, and Amount columns.
  2. Enter all your BUY transactions (investments made).
  3. Add any SELL transactions (partial redemptions), if applicable.
  4. Add a final PRESENT entry with today's date and your current portfolio value.
  5. Upload the file and click Calculate XIRR.
